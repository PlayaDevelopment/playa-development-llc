01

Tongue-and-groove ceilings

Patio, porch, and soffit ceilings in tongue-and-groove. Boards run true across the plane. Recessed lights are cut clean so the ceiling reads as one surface, not a field of patches.

Edges close. Trim wraps the plane. The run is laid out before the first board so joints land where they belong and the grain holds a consistent direction.

This is not stock decking flipped overhead. It is millwork: measured to the opening, scribed at the walls, and finished so the light finds no gap.

02

Custom casings & crown

Door and window casings, headers, and crown run as one composition. Casing, sill, and apron are built as a single architectural frame—not three pieces butted together.

Inside corners are coped. Outside corners are returned. Miters are closed so the profile never breaks. Crown is scribed to the ceiling, not caulked into a gap.

In South Florida light—high, hard, and often against glass—every joint shows. The standard is that it doesn’t.

03

Interior doors & casing

Most of the door work is inside the house. Units hung plumb, margins even, then cased so the opening reads as one piece.

Jamb, casing, and header run as one composition. A door is not done when it swings. It is done when the wrap lands as if the wall was built around it.
